同じページを 3 回も開いていませんか？ 残すのはひとつで十分。

DupTabOff は複数開いているページを見つけ、どのタブを残すかを表示し、残りをワンクリックで閉じます。固定したタブ、音楽を再生中のタブ、いま読んでいるタブには触れません。

同じページを 3 回開いた状態。DupTabOff は余分なタブを閉じて必要なひとつを残します。ほかのタブは一切動かしません。

閉じる前に、どのタブが残るか確認できる

DupTabOff のアイコンの数字が、開いている重複タブの数を示します。ポップアップを開くと重複ページが一覧表示され、残るタブと閉じるタブがわかります。

  • http と https、www、末尾のスラッシュ、トラッキングコードの違いは同じページとして扱います
  • ページを右クリックして「このページの重複を削除」を選ぶこともできます
  • 「元に戻す」で閉じたタブを復元 Pro

重複タブを開く前に防ぐ Pro

すでに開いているページへのリンクやブックマークをクリックすると、新しいタブを開く代わりにそのタブへ移動します。バックグラウンドで開いたリンクは静かに閉じるので、読んでいるページから引き離されることはありません。

  • ログイン画面、フォームの送信結果、意図して複製したタブには触れません
  • 最近防いだページは「もう一度開く」ボタン付きで一覧表示されます

どのタブも一瞬で見つかる

ポップアップで / を押して入力を始めると、すべてのウィンドウから一致するタブが表示され、Enter キーですぐに移動できます。無料版でも使えます。

タブをスヌーズして、必要なときに戻す Pro

いまタブを閉じて、今日このあと、今夜、明日の朝、来週の月曜、または好きな時刻に自動で戻せます。その時刻に Chrome が閉じていれば、次に開いたときに戻ってきます。

タブのまとまりを二度と失わない Pro

開いているタブに名前を付けてセッションとして保存し、フォルダに整理してメモを付けられます。ワンクリックで開き直すと、固定タブやタブグループも元どおり。30 分ごとの自動バックアップでクラッシュにも備えます。

  • セッションをシンプルなリンク集のページとして共有し、誰にでも送れます
  • 整理ツール：使っていないタブを閉じる、サイトごと閉じる、ウィンドウを統合する、サイト順に並べ替える

よくある質問

Gmail や Google ドキュメントなどのウェブアプリも閉じてしまいますか？

閉じるのは本当の重複だけです。Gmail などのアプリはアドレスの # 以降で画面を切り替えているため、受信トレイと開いたメールは別のページとして扱われます。固定したタブや音声を再生中のタブは閉じません。

タブの並び順がバラバラになりませんか？

なりません。DupTabOff は重複を削除するときにタブを移動せず、余分なタブを閉じるだけです。残るのは、いま見ているタブ、固定したタブ、またはタブグループ内のタブです。

無料版と Lifetime Pro の違いは？

無料版は現在のウィンドウ内の重複を削除します。最初の 200 件までは無制限、その後は 1 クリック 10 件までです。Lifetime Pro はすべてのウィンドウをまとめてチェックし、重複を開く前に防ぎ、元に戻す、色分け、スヌーズ、セッション保存、整理ツールが使えます。

Lifetime Pro はサブスクリプションですか？

いいえ。Lifetime Pro は $4.99 の買い切りで、更新料はかかりません。1 つのライセンスキーで最大 5 つのブラウザで使えます。購入前に 7 日間すべての Pro 機能を無料で試せ、解約手続きも不要です。

DupTabOff は閲覧データを収集しますか？

いいえ。タブはブラウザの中だけで読み取られ、どこにも送信されません。広告、アクセス解析、アカウントはありません。DupTabOff がインターネットに接続するのは、Pro を販売するストア Gumroad で Pro のライセンスキーを確認するときだけです。

対応ブラウザは？

Windows、Mac、Linux、ChromeOS の Chrome 88 以降と、Edge、Brave、Opera、Vivaldi などの Chromium 系ブラウザです。スマートフォン版の Chrome は拡張機能に対応していません。DupTabOff はブラウザの言語に合わせて、日本語、英語、ドイツ語、フランス語、スペイン語で表示されます。

返金はできますか？

はい。Pro がうまく機能しない場合は、購入から 14 日以内に support@purplewonton.com までご連絡ください。返金いたします。
